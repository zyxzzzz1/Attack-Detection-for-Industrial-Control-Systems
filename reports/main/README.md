# reports/main: main-line report material

**English** | [中文](README.zh.md)

Everything here is generated by scripts from the artifacts of full cluster runs (not smoke runs, `git_dirty=false`,
completed). No smoke-test number appears here. Detection metrics **do not use point-adjust**, and the threshold is the
99th percentile of the scores on `val_thr`. Start with `key_numbers.md`.

| File | Content | Generated by |
|---|---|---|

| `data_overlap.md` | The train1 / test3 data overlap in the official release: location, row counts, detection method, handling, effect on evaluation | written by hand from `data_summary.md` section 3 |
| `data_summary.md`, `attack_events.csv` | Raw data statistics; the overlap between train and test; the 50 attack events and their subsystems | `python -m scripts.hai_data_summary` |

Related files: the real alarms are in `data/processed/alerts.json` (`python -m scripts.export_alerts`); the extension
material is in `reports/extension/`. The command order from syncing cluster artifacts to generating all tables and
figures is at the end of `docs/cluster_queue.md`.

Language: `README.md`, `key_numbers.md` and `data_overlap.md` are in English. Figures, `cases.md` and the case cards
follow `ui.lang` in `config.yaml` (default `en`; set it to `zh` and rerun the commands above for Chinese). The other
tables and Markdown documents are in Chinese. The display language does not affect any number.

Constraint and decision numbers cited in these files (for example "constraint 7", "decision 6b") are listed with
their content in [`docs/design_decisions.md`](../../docs/design_decisions.md). Where a file says "CLAUDE.md", it means
that list.

## Notes for reading these results

- The low point-wise F1 is the expected result of not using point-adjust. The evaluation method was not changed to
  raise any metric.
- For every model the share of alarms on test is higher than the 1% on `val_thr`: the threshold does not transfer well
  from validation to test. The presumed cause is drift in normal operating conditions, which was not verified
  separately.
- The main configuration (W=60, hidden=64) was fixed in advance. It ranks 5th by F1 among the 9 ablation combinations
  and was not changed because of that.
- Apart from the main LSTM-AE configuration (5 seeds), all results come from a single random seed.
- The denominators of the attribution hit rates are small (53–72 alarm segments, 48–50 events) and the confidence
  intervals are wide. Always guessing P1 already gives a hit rate of about 0.68, so read the hit rates against that
  baseline.
